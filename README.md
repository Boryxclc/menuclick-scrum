# menuclick-scrum
Repositorio académico para la planificación del proyecto MenuClick aplicando la metodología SCRUM.

 # MenuClick

MenuClick es una aplicación web orientada a la gestión de pedidos en un local de comidas rápidas. El sistema permite consultar un menú digital, seleccionar productos, realizar pedidos, gestionar pagos, visualizar estados del pedido y administrar productos, descuentos y reportes.

## Objetivo del proyecto

Aplicar la metodología SCRUM para planificar, organizar y controlar el desarrollo del sistema MenuClick mediante historias de usuario, Sprint, tablero de tareas y control de versiones.

## Usuarios principales

- Cliente
- Administrador
- Cocinero
- Stakeholders

## Funcionalidades principales

- Registro e inicio de sesión
- Pedido sin registro
- Visualización del menú digital
- Carrito de compras
- Gestión de pedidos
- Pagos en línea y en caja
- Notificaciones automáticas
- Gestión de productos
- Gestión de descuentos
- Panel de cocina
- Reportes de ventas

## Metodología

El proyecto se planifica usando SCRUM, organizando el trabajo en Product Backlog, Sprint Backlog, tareas técnicas, entregables incrementales y revisión continua.
